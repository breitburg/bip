# Bip

Bip is a foundation for asynchronous AI agents.

## Running

Put the model endpoint in `.env`. It must support Chat Completions.

```
OPENAI_API_KEY=...
OPENAI_BASE_URL=https://.../v1
```

Then run `cargo run`.
